# benjamin-greenland.github.io/research

Static academic website published through GitHub Pages from the root of `main`.

## Pages and styling

The profile pages share `assets/site.css`. Keep navigation order and the active-page marker consistent when adding pages.

## Content maintenance

- Update homepage publications in reverse chronological order.
- Keep publication titles, DOI links, and award names identical across pages.
- Keep tentative dates and forthcoming activities explicitly labelled.
- The CV is available as a webpage only. Do not add downloadable PDF or DOCX copies.
- Include new public pages in `sitemap.xml`.
